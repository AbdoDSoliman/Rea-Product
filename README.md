# Rea-Product

تفكيك عميق لمنتج أو خدمة أو تقنية جديدة، وتحويل الأدلة إلى خطة عملية لبناء تجربة مماثلة.

نسخة مشتقة من [Rea-Video](https://github.com/JuneYaooo/rea-video) تحت Apache-2.0، مع الاحتفاظ بمحرك الفيديو وتاريخ المستودع. التركيز هنا على **المنتج نفسه وطريقة عمله**.

## المدخلات

- فيديو عرض أو استخدام للمنتج.
- صورة أو مجموعة صور **مع شرح** للمنتج أو السلوك المقصود.
- رابط المنتج أو توثيقه.
- يمكن الجمع بين أكثر من مصدر في نفس التحليل.

## التشغيل مع Codex

استخدم مهارة `skills/rea-product/SKILL.md` واطلب:

> استخدم Rea-Product وحلل المنتج ده بعمق: [رابط أو ملف]. فصّص الوظائف والمكونات وآلية العمل وطلع خطة نبني بيها نفس التجربة، مع الأدلة واختبارات المطابقة.

الأداة تجهز الأدلة والتقرير؛ الوكيل متعدد الوسائط يفحص المصادر ويكتب التحليل. لا يلزم مفتاح API لتشغيل أدوات التجهيز والتصدير. الرابط لا يُجلب تلقائيًا بواسطة CLI: يفتحه الوكيل بأدوات الويب. استخراج الصور من الفيديو يحتاج ffmpeg وffprobe.

من مجلد المشروع، باستخدام Python 3.10 أو أحدث:

```bash
python3 -m rea_product prepare demo.mp4 --name 'My Product' -o out/my-product
python3 -m rea_product prepare photo.png --description 'شرح المنتج ووظيفته' -o out/from-image
python3 -m rea_product prepare 'https://example.com/product' -o out/from-url
# بعد فحص المصادر واستكمال analysis.json حسب المهارة:
python3 -m rea_product report out/my-product
```

لتثبيت أوامر المشروع ومحرك الفيديو الاختياري من نفس المصدر:

```bash
python3 -m pip install -e .
rea-product --help
```

## الناتج

- تحليل الوظائف والتجربة والمكوّنات وآلية العمل الأساسية.
- معمارية تنفيذ مقترحة، عقود بيانات وواجهات أو BOM أو إجراءات تشغيل حسب نوع المنتج.
- خطة إثبات فكرة ثم MVP ثم الوصول للمطابقة، مع المهام والموارد وتقديرات التكلفة.
- سجل أدلة واستنتاجات ومجهول وخطوات تحقق، واختبارات مطابقة قابلة للتنفيذ.
- `report.html` عربي RTL، و`report.md`، و`analysis.json`، وملخص `PRODUCT.md`.

التحليل يميز بين **المشاهد، والمستنتج، والمقترح، والمجهول**. لا يدّعي اكتشاف الكود أو التفاصيل الداخلية غير المرئية. المطابقة المستهدفة محددة باختبارات؛ خطة التنفيذ وحدها لا تثبت تحققها.

## التطوير والأصل

```bash
python3 -m unittest discover -s tests_product -v
```

توثيق المشروع الأصلي محفوظ في `docs/UPSTREAM_README.md`، وتعليماته في `docs/UPSTREAM_AGENTS.md`. محرك `rea-video` ومهارته يظلان متاحين لتحليل إنتاج الفيديو عند الحاجة. التغييرات الخاصة بـ Rea-Product موجودة في `rea_product/` و`skills/rea-product/`؛ راجع `NOTICE` للنسب.
